Decision & Consensus Logic

The system evaluates all 4 classifiers independently:

  • Ensemble Threshold: If 2 or more models classify a URL as PHISHING, the overall verdict is PHISHING. Otherwise, it is LEGITIMATE.
  • Consensus Percentage: The percentage of models voting PHISHING (0%, 25%, 50%, 75%, or 100%).
  • Strict Lexical Analysis: Operates entirely without fetching HTTP content to prevent dangerous network execution.

Preprocessing Pipeline

Feature scaling adheres strictly to trained specifications:

  • Random Forest: Receives raw unscaled 25 features directly.
  • Linear SVM: Standardized using the scaler fitted during training.
  • DNN: Standardized 25-feature input passed through four dense layers.
  • 1D CNN: Standardized features reshaped to (1, 25, 1).

Deep Learning Architectures

Trained Keras neural architectures:

  • DNN Architecture: 128 → 64 → 32 → 1, using ReLU hidden activations and a sigmoid output.
  • CNN Architecture: Conv1D (64 filters, kernel size 3) → MaxPooling → Conv1D (128 filters, kernel size 3) → MaxPooling → Flatten → Dense (64) → Sigmoid output.
